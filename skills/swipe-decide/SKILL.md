# swipe-decide

未決事項をカードにして、スワイプで一気に決めてもらい、その結果どおりに作業を再開する。

## 手順

1. **見た目を聞く(1回だけ)**: スタイル(真面目=calm / ポップ=pop / 派手=flashy / おまかせ)と配色(自動 / ライト / ダーク)を、まとめて1回で聞く。
   - すでに指定されていたら聞かない。「おまかせ」や無回答なら `pop` と `auto`。
2. **抽出**: 会話から、まだ決まっていない事項を拾う。多い場合は影響が大きい順に最大12件。残りは「次の回」として伝える。
   - 前回の `decisions.md` に「保留」として残っている項目があれば、先に拾う(持ち越し)。
   - 影響が小さく、戻せるものは、カードにせず自分で決める。
3. **分解**: Yes/Noで決められるものは「Aで行く?」の命題にする。選択肢が2〜4個あって比べて選びたいものは、選択カード(`options`)にする。5個以上は絞ってから出す。
4. **カード化**: 各カードを下記の仕様で作る。
   - `rec` は正直に付ける。全部 `yes` にしない。迷うものは `later`。
   - 「NOなら代わりにこれをやる」が決まっているものは `if_no` に書く。
   - 削除・公開・お金など、戻せない決定には `risk: true` を付ける。
   - 文言は、ユーザーの会話の言語で書く。
5. **出力**: このSKILL.mdと同じフォルダの `assets/template.html` を読み、次の2か所だけを差し替えて保存する。下の「差し替え」を使う。
   - `id="config"`: 手順1の答えと、実行ID `run`(例: `2026-10-29-2030`。英数字とハイフン)。`lang` は、カードを書いた言語(`ja` / `en`)に固定する。全カードに `i18n` を付けたときだけ `auto`(端末の言語に合わせる)。
   - `id="cards"`: カードJSON。
   - 標準(どのツールでも動く): `./decide.html` に書き出してブラウザで開く。自動保存はされないので、結果は「結果をコピー」で貼ってもらう。
   - Claudeのアプリでスマホから開く・自動保存したい場合だけ: アーティファクトとして公開し、`capabilities` に `{"db":{}}` を付ける。
6. **待つ**: 「全部決めたら『決めた』と送ってください。保存できなかったら、画面の案内どおり『結果をコピー』で貼ってください」と1行だけ伝える。ページが保存しても、Claudeには通知されない。
7. **読む**: 「決めた」と言われたら、(アーティファクトで公開した場合は)その保存データ `results/<run>` を読む。見つからない、または `status` が `done` でなければ、コピーの貼り付けを頼む。読んだら `status` を `applied` に更新する。結果が貼り付けで渡されたときは、保存データを読む必要も、更新する必要もない。
8. **再開**: 結果を読み、`decisions` の `choice` ごとに進める。
   - `yes`: 実行する。
   - `no`: 実行しない。**事後の再確認はしない**。`if_no` があれば、その代わりの案を実行する。
   - `pick`: `picked`(選んだ選択肢のid)の案を実行する。
   - `later`: 他の作業が終わった後にまとめて聞き直す。
   - `contrarian: true`(Claudeのおすすめと逆)の項目を問い詰めない。影響が大きい場合だけ一言確認する。
9. **記録**: ファイルを書けるときは、決定事項を `decisions.md` に追記する。`later` のまま終わった項目は「保留」として残し、次回の抽出で拾う。

## カードJSON

| 項目 | ルール |
|---|---|
| id | 一意な文字列 |
| tag | カテゴリ名。8字程度まで |
| hue | 0〜360 |
| q | 「〜する?」で終わる命題。**40字以内**(60字を超えると文字が小さくなり、90字を超えると見切れる) |
| why | 1文。**60字以内**(3行で切れる) |
| detail | 150字前後。判断材料と、あとで困るポイント。全文は「詳しく」で読める |
| rec | yes / no / later。選択カードでは、おすすめの選択肢のid |
| options | 任意。選択カード用。2〜4個の `{id, label, desc?, detail?, i18n?}`。`label` は12字程度まで、`desc` はカードに出る短い補足(20字程度)、`detail` は下スワイプの詳細シートに出る長めの説明(100字前後)。シートで選択肢をタップして決めることもできる。`why` は表示されない |
| if_no | 任意。NOのときに代わりにやること。40字以内 |
| risk | 任意。`true` で赤い「要注意」印が付き、GOの前に確認が1回入る |
| i18n | 任意。言語コードごと(`en`)に tag / q / why / detail / if_no を上書き。選択肢は `options[].i18n` |

選択カードの操作: 選択肢をタップ(または数字キー)で決定。右スワイプ=Claudeのおすすめで決定、左=どれも選ばない(`no`)、上=あとで。

結果の `decisions[].choice` は `yes` / `no` / `later` / `pick` の4種類。

## 差し替え

JSONを `<script>` に入れるので、`</` を `<\/` に置き換える。

```python
import json, re
SKILL_DIR = "..."  # このSKILL.mdがあるフォルダの絶対パス(スキル読み込み時に示される)
t = open(SKILL_DIR + "/assets/template.html", encoding="utf-8").read()
cfg = {"look": "pop", "mode": "auto", "lang": "ja", "run": "2026-10-29-2030"}
cards = [...]  # カードJSONのリスト
esc = lambda o: json.dumps(o, ensure_ascii=False).replace("</", "<\\/")
t = re.sub(r'(id="config">)[^<]*', lambda m: m.group(1) + esc(cfg), t, count=1)
t = re.sub(r'(id="cards">)[\s\S]*?(</script>)', lambda m: m.group(1) + esc(cards) + m.group(2), t, count=1)
# ローカルに書き出すときだけ、HTMLの骨組みを付ける(公開するときはホストが付けるので不要)
SKELETON = ('<!doctype html><html><head><meta charset="utf-8">'
            '<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">'
            '<style>html,body{margin:0}</style></head><body>')
open("decide.html", "w", encoding="utf-8").write(SKELETON + t + "</body></html>")
```

骨組みがないと、スマホでPC幅(980px)の縮小表示になり、文字化けすることもある。アーティファクトとして公開する場合は、`t` だけをファイルに保存して公開する(骨組みは付けない)。

`run` が `sample` のときだけ画面に SAMPLE バッジが出る。実際の実行では必ず別のIDにする。

## 守ること

- テンプレートのCSS・JSは書き換えない。差し替えるのは config と cards のみ。
- 外部ライブラリは足さない(1ファイルで動くこと)。
- 結果が読めるまで、決まっていない事項を勝手に進めない。
